How to search

The same syntax works in every filter box, in the header search and in the terminal. Click an example to try it.

Words
anything mentioning it - hosts, names, services, products, versions, page titles, URLs, technologies
several words: all of them
exactly this text (a leading ')
starts with / ends with
without it
rows that contain the words come first and alone; ~ also lists those that only contain the letters, scattered (a typo's best friend)
Addresses
addresses beginning with it: .1, .10-.19, .100-.199
exactly this host (also 10.10.10.1/32)
a range; several ranges or addresses side by side are either one
Ports
a port with that number, whatever its state
a port in that state (closed means not open: closed or filtered)
that host with that port
Services
a port running it; side by side they describe one port
Combining
AND, OR (or |), NOT in capitals, and ( )
either

Under every filter a line says how your text was read - check it when a result looks wrong.
